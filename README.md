# ⚡ OmniFetch

**One Command. Multiple APIs. Endless Discovery.**

OmniFetch is a JavaScript-based multi-API search tool that fetches information from different APIs through a single input field. Just enter a command to explore Pokémon details, GitHub profiles, random cat facts, jokes, and TV shows!

## ✨ Features

- 🐉 **Pokémon Search** — Get Pokémon names, height, weight, and sprites.
- 🐙 **GitHub Lookup** — View GitHub user profiles and follower counts.
- 🐱 **Cat Facts** — Discover random facts about cats.
- 😂 **Random Jokes** — Get jokes with setups and punchlines.
- 🎬 **TV Show Search** — Explore show details, language, status, and ratings.
- 📋 **Copy Commands** — Copy example commands with one click.
- ⚡ **Async Data Fetching** — Fetch API data using JavaScript's `async/await`.

## 🌐 APIs Used

| API | Purpose |
|---|---|
| [PokéAPI](https://pokeapi.co/) | Pokémon information |
| [GitHub REST API](https://docs.github.com/en/rest) | GitHub user profiles |
| [Cat Fact API](https://catfact.ninja/) | Random cat facts |
| [Official Joke API](https://official-joke-api.appspot.com/) | Random jokes |
| [TVmaze API](https://www.tvmaze.com/api) | TV show information |

## 🚀 How to Use

1. Clone or download this repository.
2. Open the project folder.
3. Launch `index.html` in your browser.
4. Enter a command in the input field.
5. Click the search button to fetch the result.

## 💻 Example Commands

```text
pokemon pikachu
github torvalds
catfact
joke
movie batman
```

**Note:** Pokémon names and GitHub usernames should be entered after their respective commands. Cat facts and jokes do not require an additional value.
